Easy-MCP

FastAPI for MCP servers. Write a typed Python function, add one decorator, and any AI assistant that speaks MCP can call it. Schemas, input checks, API-key auth, rate limits and timeouts are on by default, and the database connectors stop the query itself when a call is cancelled.
